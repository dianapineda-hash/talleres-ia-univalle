Cómo se calculan las métricas

Exactitud = etiquetas iguales a la referencia / casos evaluados. Cobertura de respuesta = respuestas distintas de Abstención / casos evaluados. Riesgo selectivo = respuestas incorrectas entre las no abstenciones / respuestas no abstentas. Un error crítico es una respuesta incorrecta no abstenta en un caso marcado crítico.

La referencia Abstención significa evidencia insuficiente, no conclusión negativa. Si no hay respuestas, el riesgo es no estimable. Se muestran los denominadores y los casos faltantes. No se calculan pruebas de superioridad ni intervalos: el conjunto pequeño y seleccionado no permite una inferencia poblacional fiable.
